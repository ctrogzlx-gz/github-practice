# github-practice

这是一个 GitHub 学习练手仓库。配套文档：`GitHub学习计划.md`

## 目录结构

```
github-practice/
├── README.md          ← 你正在看的文件，第2章会把它改写成正式项目主页
├── .gitignore         ← 告诉 Git 哪些文件不要记录（已预置游戏开发常用忽略项）
├── index.html         ← 第2章 GitHub Pages 练习用的展示页
├── styles.css         ← 展示页样式
├── assets/            ← 模拟美术资源目录（占位文件，用来练习忽略规则）
└── notes/ideas.md     ← 灵感笔记，第1章用来练习第一次提交
```

## 使用约定

- 每一章的作业都在这个仓库里完成，做完计划 ≈ 这个仓库已规范托管在 GitHub 上
- 真实项目练熟后，把同样的流程套到你自己的游戏/软件项目上
